# 🩺 Practo Clone

A responsive healthcare appointment booking website inspired by Practo.

## Features

- Doctor Listing
- Appointment Booking
- Medicine Section
- Clinic Information
- Lab Tests
- Video Consultation
- Responsive Design

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

```text
Practo Clone/
│

├── clinic.html
├── doctors.html
├── lab.html
├── medicine.html
├── video.html
├── style.css
├── script.js
├── README.md
└── .gitignore
```

## How to Run

1. Download or clone the repository.
2. Open `index.html` in your browser.
